# Personal Portfolio – Hemalatha D

A responsive, accessible, multi-page personal portfolio built using semantic HTML5, CSS3, and JavaScript.

## About the Project

This project showcases my education, technical skills, professional experience, and projects through a clean and user-friendly portfolio website.

## Pages

- **Home:** Personal introduction and portfolio overview.
- **About:** Education, skills, and professional experience.
- **Projects:** Details of my academic and development projects.
- **Contact:** Accessible contact form with client-side validation.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Accessibility Features

- Semantic HTML5 elements
- Skip-to-content navigation
- Keyboard accessibility
- Visible focus indicators
- Accessible form labels and validation messages
- ARIA attributes and live regions
- Responsive design

## SEO Features

- Unique page titles and meta descriptions
- Open Graph metadata
- Semantic heading structure
- Appropriate language declaration
- Search engine indexing metadata

## Testing and Validation

- HTML validation using Nu HTML Checker
- Accessibility review using keyboard navigation
- Lighthouse testing across all four pages

**Lighthouse results:** 100/100 in Performance, Accessibility, Best Practices, and SEO for all four pages.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
